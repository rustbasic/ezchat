# rweb search sources guide

## 목적
- 이 문서는 `rweb`로 웹 검색이나 정보 수집을 할 때, 어떤 사이트를 우선 참고하면 좋은지 빠르게 판단하기 위한 참고용 가이드입니다.
- `guides\rweb.md`가 `rweb` 명령 사용법을 설명한다면, 이 문서는 `어디를 먼저 볼지`와 `어떤 종류의 출처를 우선할지`를 정리합니다.
- 이 문서는 시작점 모음이며, 더 좋은 정보원이 보이면 계속 보강합니다.

## 기본 원칙
- 아래 사이트 목록은 자주 유용한 출발점이지, 반드시 그 사이트만 보라는 뜻은 아닙니다.
- 찾으려는 정보와 더 직접적으로 맞는 공식 문서, 원문, 전문 사이트, 커뮤니티 글, 블로그, 릴리즈 노트가 있으면 그쪽을 우선 참고합니다.
- 검색 엔진 결과는 입구로 쓰고, 중요한 사실이나 최신 정책은 가능하면 원문 문서에서 다시 확인합니다.
- 커뮤니티 글은 동향 파악에 좋고, 공식 문서는 확정 정보 확인에 더 적합합니다.
- 날짜에 민감한 주제는 검색어에 연도, 월, 버전명을 함께 넣는 것이 좋습니다.
- 한국어 결과가 약하면 같은 주제를 영어 키워드로 한 번 더 찾습니다.

## 언어별 시작점

### 한국어 일반 검색
- Naver
  - 메인: `https://www.naver.com/`
  - 검색 예시: `https://search.naver.com/search.naver?query=2026+AI+트렌드`
- 필요하면 Google 한국어 검색 결과도 함께 비교합니다.

### 영어 일반 검색
- Google Search
- DuckDuckGo
- Bing
- 영어권 공식 문서, 블로그, GitHub, 기술 문서 사이트를 함께 확인합니다.

## 주제별 추천 출처

### IT / 개발 뉴스
- GeekNews
  - `https://news.hada.io/`
- Hacker News
  - `https://news.ycombinator.com/`
- 기술 뉴스는 커뮤니티에서 빠르게 흐름을 보고, 중요한 내용은 원문 링크로 다시 확인합니다.

### Rust
- docs.rs
  - API 확인용
- The Rust Blog
  - `https://blog.rust-lang.org/`
- crates.io
  - crate 존재 여부와 최신 버전 확인용
- GitHub
  - release, issue, discussion, README 확인용
- Rust 관련 정보는 가능하면 공식 문서와 crate 문서를 먼저 보고, 커뮤니티 글은 보조 참고로 사용합니다.

### AI
- OpenAI blog / docs
- Google AI / Gemini docs
- Anthropic docs
- Hugging Face blog / docs
- AI 정보는 변화가 빠르므로, 커뮤니티 요약만 보지 말고 공식 문서나 발표 원문을 같이 확인합니다.

### 제품/라이브러리 사용법
- 공식 문서
- 공식 GitHub README / release notes / issues
- 예제 코드 저장소
- Stack Overflow 또는 관련 커뮤니티
- 사용법 문제는 검색 엔진보다 공식 문서와 저장소 내 예제를 먼저 찾는 편이 더 정확할 때가 많습니다.

### 증권
- 한국거래소(KRX)
  - 시장 제도, 시장 통계, 상장 관련 기본 정보 확인용
  - `https://www.krx.co.kr/`
- 금융감독원 전자공시시스템(DART)
  - 기업 공시, 사업보고서, 분기/반기 보고서, 주요사항 보고서 확인용
  - `https://dart.fss.or.kr/`
- 기업 IR 사이트
  - 실적 발표자료, 실적 설명회 자료, 프레젠테이션, 배당/주주환원 정책 확인용
- Yahoo Finance, Reuters, Investing.com
  - 종목 개요, 실적 일정, 해외 종목 뉴스, 시장 반응 확인용
- 증권 정보는 기사 요약만 보지 말고 공시, 실적 발표자료, 기업 IR 자료를 우선 확인하는 것이 좋습니다.

### 경제
- 한국은행
  - 기준금리, 통화정책, 경제통계, 공식 보고서 확인용
  - `https://www.bok.or.kr/`
- 통계청 국가통계포털(KOSIS)
  - 물가, 고용, 생산, 인구 등 공식 통계 확인용
  - `https://kosis.kr/`
- 기획재정부 / 금융위원회
  - 정책 발표, 보도자료, 제도 변경 확인용
- Trading Economics, Reuters
  - 해외 거시 지표 일정, 주요국 경제 뉴스, 국제 경제 이슈 확인용
- 연합인포맥스, 한국경제, 매일경제, 연합뉴스 등 주요 경제 뉴스
  - 경기 흐름과 속보 파악용
  - 다만 중요한 수치와 제도 변화는 반드시 중앙은행·정부기관·공식 통계로 재확인합니다.
- 경제 정보는 뉴스 요약만 믿지 말고 중앙은행, 정부 발표, 공식 통계를 우선 확인하는 것이 좋습니다.

## 검색 전략 예시
- 한국어 트렌드 파악
  - Naver 검색으로 전체 흐름 확인
  - 필요하면 기사/블로그에서 반복 언급되는 핵심 키워드를 다시 검색
- 개발 뉴스 파악
  - GeekNews나 Hacker News에서 화제가 되는 링크를 먼저 확인
  - 중요한 내용은 원문 블로그나 공식 릴리즈 노트로 이동
- 라이브러리 오류 해결
  - 공식 문서 → GitHub issue → 검색 엔진 순으로 확인
- 최신 정책/가격/지원 모델 확인
  - 검색 결과 요약보다 공식 pricing/docs/changelog 페이지를 우선 확인
- 국내 증권 확인
  - 시장 뉴스로 흐름을 먼저 보고, 기업 정보는 DART 공시와 IR 자료로 다시 확인
  - 상장, 공시, 시장 제도는 KRX와 기업 공시 원문을 우선 확인
- 국내 경제 확인
  - 경제 뉴스로 이슈를 파악한 뒤, 거시 지표와 정책은 한국은행, KOSIS, 기획재정부, 금융위원회 자료를 우선 확인
- 해외 증권 확인
  - Reuters, Yahoo Finance 등으로 시장 이슈를 본 뒤, 기업 실적 발표문과 IR 자료 원문으로 재확인
- 해외 경제 확인
  - Reuters, Trading Economics 등으로 흐름을 본 뒤, 중앙은행·정부 통계 원문으로 재확인

## 보강 규칙
- 새로 자주 쓰게 된 사이트가 있으면 이 문서에 짧게 추가합니다.
- 특정 주제에서 반복적으로 품질이 좋은 사이트가 확인되면 `주제별 추천 출처`에 올립니다.
- 반대로 오래되었거나 품질이 낮은 사이트는 우선순위를 낮추거나 제거합니다.
- 추천 사이트 예시는 유지하되, 더 적합한 정보원이 있으면 그곳을 유연하게 사용한다는 원칙을 항상 우선합니다.
